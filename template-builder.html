      How to paste into Salesbuildr
      1. In Salesbuildr, create a new, blank quote template and give it a name — e.g. Security Package — Acme IT.
      2. Add a widget to the template for each widget you copy here. Use a widget type that supports products, so reps can add products under each section.
      3. Open the widget's editor. If the toolbar has a source code button (<>), open it and paste there — that keeps the formatting exactly. Otherwise paste straight into the editor.
      4. Save the widget, then come back and select Copy next for the following widget. Ticks show which widgets you've already copied.

      Copy all puts every selected widget into one paste — quickest, but it all lands in a single widget. Copy one at a time if you want reps to add products under each section.

      Why this works

      Most MSP proposals fail before they're read. Pricing on page one. Legal on page two. The customer hasn't been given a single reason to care yet.

      The 8 widgets — and what each one does for the sale

      Banner
      Sets the visual tone immediately. Professional, branded, engagement-specific.
      Cover Letter
      The personal opening. Uses the client's name, written by a named person. Signals care.
      Executive Summary
      For busy decision-makers who won't read everything. One page. Three outcomes.
      W1 Their Situation
      Shows the customer you've listened. They read their own reality back — that alone sets you apart.
      W2 Why Now
      Creates urgency without pressure. Connects the cost of inaction to something already happening in their world.
      W3 What We Do
      Positions you as the expert. Not a feature list — a clear explanation of the outcome they're buying.
      W4 Why Us
      Answers the question every buyer is silently asking. Differentiates on trust and track record, not price.
      W5 Next Steps
      Removes the last objection before they sign. Makes it easy to say yes.

      Before you send

      Check the statistic in W2 and its source, and add your real certifications and track record to W4. The AI deliberately leaves those generic so nothing is made up.

      After you push

      1. Open Salesbuildr → Templates and find your new template.
      2. Start a new quote from it.
      3. Use the Add Products option on each widget to add your services and pricing.
      4. Edit any widget copy that needs personalising for this client.
      5. Send.
